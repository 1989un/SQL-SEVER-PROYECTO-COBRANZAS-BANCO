##
# Proyecto SQL: Análisis de Gestión de Cobranzas en Banca


<table>
    <tr>
        <td><h2>Resumen (Overview)</h2></td>
        <td colspan="2" ><p><i>El área de cobranzas de una entidad bancaria busca optimizar la recuperación de deudas, reducir los niveles de morosidad y mejorar la eficiencia en la gestión de su cartera de créditos. Sin embargo, actualmente no cuentan con una visión clara y consolidada de los datos relacionados con clientes, créditos y comportamiento de pago.</i></p><p><i>Mi objetivo es utilizar SQL dentro de SQL Server Management Studio para analizar la información disponible, identificar patrones de morosidad, evaluar el desempeño de la cartera y generar indicadores clave que permitan tomar decisiones estratégicas. A partir de este análisis, se brindarán recomendaciones que contribuyan a mejorar la gestión de cobranzas, priorizar clientes de alto riesgo y maximizar la recuperación de deuda.</i></p>
